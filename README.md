How to run 

1. Open new terminal on coding IDE
2. Execute command "git clone https://github.com/alyssap30/IT-Asset-Management-System"
3. Run program on "main.py"

Features 

- Event Driven programming 
- The use of classes
- Tkinter GUI Library
- SQL Lite built-in python library
- SQL CRUD Operation execution 
- User input validation 
- Error handling using try/except
- String methods
